# CMPN 3000 Project Phase 2
* Created by: Xavier Yick
* Creation date: Fall 2026 (Year 1)

## Overview
* This project is a simple echo app which takes the inputs from the client, and returns an uppercase version from the server.
* Unlike Phase 1, this app implements TLS.
* It can be run using two terminal windows on one machine, by running ```python FILENAME```.
* To close the programs, type ```exit``` into the client-side terminal window.
